# Chasqui: A Bounded Judge for Model Output

Chasqui is a bounded judge designed to verify output from large language models. It acts as a judge, but has strict limits on what it can check. This bounded scope allows it to provide judgments that are more accurate and reliable than if it were tasked with exploring the entirety of a model's output.

## Usage

To use Chasqui, you need to provide it with the following information:

1. The claim that you want the model to verify.
2. A specific file that the model is claiming is accurate.
3. The specific line number within that file that the model is claiming is accurate.

Chasqui will then read the file and check the specified line number to determine if the claim is accurate. If the claim is accurate, Chasqui will return a verdict of "CONFIRMED". If the claim is inaccurate, Chasqui will return a verdict of "DENIED".

## Example

Suppose you have a file called `example.py` with the following content:

```python
def foo():
    return 'bar'
```

And you want to verify that the model claims that `example.py:2` is accurate. You would then use Chasqui like this:

```python
from chasqui import Chasqui

chasqui = Chasqui()
lines = chasqui.get_lines('example.py', 1)
print(lines)  # Output: ['def foo():']
```

This would return a verdict of "CONFIRMED" if the model claims that `def foo():` is accurate, or "DENIED" otherwise.

## Why It Matters

Chasqui is useful because it provides a way to verify specific claims made by models without having to explore the entire output of a model. This allows for more accurate and reliable judgments to be made, and helps to ensure that models are producing high-quality output.
