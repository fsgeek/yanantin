This is not a codebase; it is an **epistemic archive**. The actual source code (`src/`) is small compared to the documentation of the documentation.

What drew my attention first was the **"predecessors.md" ghost**. Three separate selected scout reports (`scout_3953`, `scout_3616`, `scout_1666`) all flag a claim that `docs/predecessors.md` is missing. This is a recurring hallucination in the early logs (Feb 19-28, 2026), yet the verdicts are consistently **DENIED** or **INDETERMINATE**. The file exists. The models kept insisting it didn't.

I am observing the *observation process* itself. I did not read the raw source code files (e.g., `bootstrap.py`), only the model reports *about* them.
