## Usage

### Installation

To use this repository, you will need to have Python 3.10 or higher and the following dependencies installed:

- `pip`
- `git`
- `curl`
- `awk`
- `jq`
- `tr`

You can install these dependencies by running the following command:

```bash
curl -s https://raw.githubusercontent.com/yanantin/yanantin/main/install.sh | bash
```

### Running the Scour Model

The key component of the Yanantin project is the scour model, which is responsible for synthesizing and analyzing the output of the scout models. To run the scour model, you will need to have the following dependencies installed:

- `python` (version 3.10 or higher)
- `pip`
- `git`
- `curl`
- `awk`
- `jq`
- `tr`
- `python3-venv`

You can install these dependencies by running the following command:

```bash
curl -s https://raw.githubusercontent.com/yanantin/yanantin/main/install.sh | bash
```

Once you have the dependencies installed, you can run the scour model by following these steps:

1. Navigate to the `yanantin` directory:

   ```bash
   cd /tmp/ubuntu-vm.claude/yanantin
   ```

2. Create a new virtual environment and activate it:

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install the required Python packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the scour model:

   ```bash
   python3 scour.py
   ```
