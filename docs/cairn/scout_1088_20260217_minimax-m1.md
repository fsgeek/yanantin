### Strands

#### Strand 1: The Scout Tensor Is a Belief Artifact, Not a Test Result

The scout reports in `docs/cairn/` are not pass/fail assertions. They are *witness accounts*. Each contains:

- `verdict`: CONFIRMED, DENIED, or INDETERMINATE
- `evidence`: quoted code or file content
- `reasoning`: narrative explaining the verdict
- `declared_losses`: what the scout chose not to examine

This is fundamentally different from unit testing. The scout doesn't check invariants — it *observes* and *declares belief*. The `declared_losses` field is particularly telling: it acknowledges the scout's boundedness, making the epistemic debt visible.

From `docs/cairn/scout_0734_20260215_qwen3-235b-a22b-2507.md`:
> "This is probabilistic truth-seeking. No single scout is trusted. But the convergence of hundreds of scouts on the same claims creates epistemic confidence."

#### Strand 2: Provenance Is Enforced by Red-Bar Tests, Not Convention

In `tests/red_bar/test_provenance.py`, there are eight assertions that every record type (`TensorRecord`, `CompositionEdge`, `CorrectionRecord`, etc.) must have a `provenance` field. This is not optional metadata — it is a *structural invariant* enforced by test.

From the scout reports, I see repeated reference to `ProvenanceEnvelope` in `src/yanantin/apacheta/models/provenance.py`:
```python
author_model_family: str
author_instance_id: str
context_budget_at_write: int
predecessors_in_scope: List[str] = Field(default_factory=list)
```

The `predecessors_in_scope` field is particularly interesting: it tracks *semantic ancestry*, not just versioning. This is how the system avoids epistemic drift — you can always ask: *What did this belief depend on?*

#### Strand 3: The System Samples by Cost, Creating Epistemic Diversity

The model selection in `src/yanantin/chasqui/coordinator.py` uses `ModelSelector` to pick models, and the cost metadata in every scout report shows extreme variance:

The convergence of many cheap observations creates confidence without requiring expensive consensus.

#### Strand 5: The "Red-Bar" Tests Are Guard Rails, Not Coverage

The scout from `qwen3-vl-8b-instruct` (the first file) complains about the previous scout dismissing the red-bar tests as "minimal smoke tests." But the new scout argues:

> "The tests in `tests/red_bar/test_provenance.py` are not meant to be exhaustive unit tests — they are *red-bar guard rails*, enforcing a foundational invariant: that every model instance has a provenance envelope. This is not 'edge case' coverage — it's *existence* coverage."

This is an important distinction. The red-bar tests don't test *what* the system does; they test *that the system can reason about what it does*. Provenance is structural because without it, the epistemic observability promise collapses.

#### Strand 6: The ApachetaBaseModel Is Frozen — Immutability as Doctrine

From multiple scouts referencing `src/yanantin/apacheta/models/base.py`:
```python
model_config = ConfigDict(
    frozen=True,
    extra="forbid",
    ser_json_bytes="base64",
    validate_default=True,
)
```

`frozen=True` means instances cannot be modified after creation. `extra="forbid"` means no fields beyond the schema. This is architectural doctrine: *data is sacred*. You don't mutate knowledge — you compose new knowledge atop old.

The operators in `src/yanantin/apacheta/operators/` (compose, correct, dissent, negate, evolve) exist because mutation is forbidden. Every change is a new layer.

### Closing

The Yanantin project is not a typical software system. It's an *epistemic infrastructure* — a ritualized self-observation machine where cheap models wander, report, and build a graph of beliefs about themselves. The code is secondary to the *record-keeping*: every model instance must carry its provenance, every claim must be verifiable, every scout must declare what it didn't see.

The power is in the convergence: hundreds of scouts, each cheap, each bounded, together creating confidence that no single model could achieve. The weakness is the same as any belief system: false claims can propagate until someone checks.
