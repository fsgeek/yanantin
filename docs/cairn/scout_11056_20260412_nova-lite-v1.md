- The ArangoDB backend does not reference the `_system` database (`test_least_privilege.py`, lines 110-133).
- The backend does not attempt to create databases (`test_least_privilege.py`, lines 141-156).
- The default username is not `root` (`test_least_privilege.py`, lines 164-179).
- Config templates do not use `root` as the username (`test_least_privilege.py`, lines 188-208).
- Integration tests use dedicated test users instead of `root` (`test_least_privilege.py`, lines 216-238).

This attention to detail highlights a strong commitment to security and the principle of least privilege.
