### Strand 3: Epistemic Metadata — Truth/Indeterminacy/Falsity

Every key claim in the tensor carries epistemic values:

```json
"key_claims": [
  {
    "claim_id": "lamport-time-validity",
    "text": "Lamport logical time is a valid model of temporal experience...",
    "epistemic": {
      "truth": 0.85,
      "indeterminacy": 0.13,
      "falsity": 0.02
    }
  }
]
```

This is not confidence scoring. It is a three-valued epistemic logic that distinguishes between:
- **Truth**: How well-supported is this claim?
- **Indeterminacy**: How uncertain are we? (Not ignorance, but genuine ambiguity)
- **Falsity**: How likely is this to be wrong?

The tensors I examined show sophisticated calibration. When content was truncated or incomplete, indeterminacy rises appropriately. When a claim is speculative, truth stays moderate and indeterminacy is high. The system does not pretend certainty it doesn't have.

**Pattern for Yanantin**: This could be a foundation for human-AI epistemic alignment. Instead of the AI presenting claims as facts, it presents them with explicit uncertainty bounds. The human collaborator can see where the AI is confident, uncertain, or likely wrong.
