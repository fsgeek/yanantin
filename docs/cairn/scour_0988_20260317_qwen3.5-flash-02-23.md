The project's most concrete technical contribution: context windows are unmanaged physical memory, and the solution is virtual memory, not compression.

**Key findings:**

- T31: "The context window is not analogous to unmanaged physical memory. It IS unmanaged physical memory."
- T32: "The context window is L1 cache. Nobody is building the rest of the hierarchy."
- T34: "280 models tested. 258 scored 6/8 or better. 163 scored perfect 8/8." (structured memory protocol)

**Architecture:**
- Pichay: Context pager/gateway with eviction, fault handling, yuyay protocol

- The bridge: Pichay's eviction → Yanantin's storage (not yet built)

**Significance:** This reframes the entire problem. Prior work (LLMLingua, ACON, SWE-Pruner) treats context as content to be compressed. This project treats context as memory to be managed. The paper's claim: "Non-inferiority at 37% reduced cost is the complete argument. Superiority is future work." (T30)
