## Strands

### 1. **The Jabberwock as a Testbed**
- **Purpose:** The Jabberwock is an experimental NER system built to test edge cases, especially those where pattern matching fails and reasoning is required.
- **Observation:** The author explicitly contrasts this system with a conventional ER system, suggesting that the system’s behavior (e.g., missing deduplication, lack of order in results) reflects reasoning rather than retrieval, and that these behaviors are intentional.
- **Claim:** The Jabberwock is “how it speaks to the future” — that is, its naming and structure are designed to force future systems to reason rather than rely on compressed, pattern-matching defaults.

### 2. **Four Core System Bugs**
- **Mome lifecycle incomplete**
- **Empty strings accepted**
- **Claim noise in resolved view**
- **No observation ordering**
- **Theme:** All bugs cluster around a design flaw called “the Frabjous fold was dumb,” meaning that the system collects all data without proper structuring or sorting.
- **Consequence:** The bugs are not errors to be fixed, but “data” that reveal the system’s design principles.

### 3. **Deserialization Hazard and Forward Compatibility**
- **Issue:** New validation constraints on existing fields caused deserialization errors.
- **Fix:** `_load_all` now logs and skips bad records, but the problem remains for historical data.
- **Meta-insight:** This is a *time bomb* in event-sourced systems, where schema evolution must be handled carefully.

### 4. **The Grokking Distinction**
- **Tony’s observation:** Pattern matching (retrieval) vs. grokking (reasoning).
- **Evidence:** Bugs in the Jabberwock suggest reasoning rather than retrieval — deduplication, claim filtering, and ordering were absent precisely because the Jabberwock names prevent pattern-matching defaults.
- **Implication:** The bugs are the “fingerprint” of construction, not error.

- **Implication:** The naming defense is a memetic strategy — not just for construction, but for future systems that might encounter this repository.

### 6. **The Arbiter’s Coherence Theorem**

- **Meta-insight:** The theorem was only articulated later, but the Jabberwock’s design embodies it before articulation.
