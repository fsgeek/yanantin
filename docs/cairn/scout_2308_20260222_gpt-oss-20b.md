### Preamble  
I opened the repo from the root directory, first looking at the top‑level *docs/cairn* folder.  It contains dozens of Markdown files all named in the pattern  

```
scout_<run>_<timestamp>_<model>.md
```

Each file starts with a fenced comment block that lists the LLM used, token counts, cost, and a claim that the file is meant for a “verify” dispatch.  The body of the file then contains a short “Claim” line, a reference to the file being claimed about (`ClaimFile`), the model that made the claim (`ClaimBy`), and a `SourceTensor` link to another scout report that presumably generated the claim.  Below the claim, a verdict (`CONFIRMED`, `DENIED`, or `INDETERMINATE`) and an evidence block follow, sometimes with code snippets.

The pattern is consistent across the entire *cairn* directory: header, claim, verdict, evidence, declared losses, open questions, and closing.  The files are very small (most are < 200 lines), so a quick scan gives a sense of what the scavenger is doing: each run is a lightweight “proof‑of‑concept” that a claim can be verified against a target file or test case.

I started with a few representative files to see how the content is actually structured.
