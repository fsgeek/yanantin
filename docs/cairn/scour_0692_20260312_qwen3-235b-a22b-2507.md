#### **1. Temporal Integrity via UTC Enforcement**  
In `models.py`, the `_ensure_utc()` function and its use in `FactRecord` and `MemoryAnchor` validators enforce timezone-aware timestamps normalized to UTC. This is non-negotiable across all backends.

- **What I saw**: Naive datetimes are rejected outright (line 25–34). Every model with a timestamp uses a validator to apply `_ensure_utc()` (e.g., `FactRecord._normalize_timestamp`, line 58).
- **Why it matters**: ISO 8601 sorting only works reliably when offsets are consistent. UTC ensures lexicographic sort order matches chronological order — essential for temporal queries in ArangoDB, DuckDB, and in-memory bisect.
- **Assumption**: All clients emit UTC or include timezone info. If a provider sends a non-UTC-aware timestamp, it fails early.
- **Connection**: This assumption propagates upward — any collector feeding facts must respect it. A misconfigured client would break silently in some backends (DuckDB stores as string) but fail loudly here, which is correct.
- **Risk**: If this validation were removed or bypassed (e.g., via model_dump without validation), temporal queries could return incorrect results due to mixed offsets.

> ✅ **This is a strength**: correctness is enforced at the domain model level, not left to backend quirks.

#### **5. Ephemeral Views, Frozen Tensors**  
The lifecycle from `MemoryAnchor` → `AnchorView` → `TensorRecord` embodies the **epistemic pipeline**.

- **What I saw**: `AnchorView` is "ephemeral", built fresh on `materialize()` (line 181). It includes *all current providers*, even those not in the original anchor — this is **late binding**.
- **Implication**: A view is not a snapshot of the past, but a *current interpretation of the past*. New providers register retroactively.
- `freeze()` then pins this live interpretation into an immutable tensor, with structured provenance and content.
- **Missing**: No versioning of views. You can't re-materialize an old view unless you re-run `materialize()` — but the result may differ due to new providers.
- **Risk**: Non-reproducibility. Two freezes of the same handle at different times may yield different tensors.
