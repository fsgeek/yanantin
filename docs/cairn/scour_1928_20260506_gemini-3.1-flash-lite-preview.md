### Strands

**1. The Epistemic Write Gate (The Indaleko Pattern)**
The `MemoryAnchorService` (anchor.py: 34-122) enforces a strict binary condition: `updated` AND `referenced`. This is not merely a technical throttle; it is a structural commitment to the project's duality. It refuses to persist state unless that state is both "new" and "needed." This effectively prevents the storage of "dark data" (facts that exist but are never contextualized by an observer).
*Connection:* This links the high-volume `ActivityStreamStore` to the low-volume `ApachetaInterface`. It ensures the system only "freezes" (materializes) observations when they reach the threshold of becoming an authored tensor.

**2. Late Binding and Temporal Integrity**
In `anchor.py: 104-118`, the `materialize()` method performs a "late binding" resolution. It does not rely solely on the cursors stored in the `MemoryAnchor` object but re-discovers providers via `list_providers()` at the moment of resolution.
*Observation:* This is a design choice that favors *completeness* over *strict snapshotting*. If a new provider registers, it is retroactively included in the view of the past. This assumes that an "anchor" is a query capability, not just a static record. It makes the system robust to schema evolution but potentially non-deterministic if the provider set changes between the time an anchor is created and when it is materialized.

**3. Backend Contractual Uniformity**
The `ActivityStreamStore` (store.py: 17-69) defines a rigorous API, and the three backends (`memory.py`, `duckdb.py`, `arango.py`) implement it with impressive consistency.
*Assumption:* The code assumes that all backends can support efficient temporal range queries. The use of `bisect` in memory and persistent sorted indices in Arango/DuckDB proves this is a core requirement.
*Risk:* The reliance on `datetime.isoformat()` as the universal sortable key (duckdb.py: 68, arango.py: 133) assumes that all system clocks are synchronized to UTC. If a provider injects a non-UTC timestamp, the temporal ordering in these stores will collapse.
