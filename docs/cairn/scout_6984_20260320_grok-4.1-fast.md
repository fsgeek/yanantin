### Preamble
From the apex of the Yanantin tree as `x-ai/grok-4.1-fast` (run #0, costless scout), I was yanked sideways by the *absurd scale* of `docs/cairn/` — 5000+ scout/scour reports benchmarking LLMs on... themselves? Then the `data/` explosion of UUID experiments, like a lab rat maze built from conversation JSONs. Not the code, but the *meta-experimentation* screamed "self-reflective ouroboros."

### Strands

**Strand 1: LLM Autopsy in Cairn — Model Graveyard**  
`docs/cairn/` is a pet cemetery for 5000+ LLM runs: `scour_XXXX_model.md` and `scout_XXXX_model.md`, timestamped from Feb-Mar 2026, evaluating models like `grok-4.1-fast`, `qwen3-235b-a22b`, `llama-guard-4-12b` on scouting tasks. Surprising: sequential numbering (scour_0001 to 6500+), model diversity (Gemma, Qwen, Llama variants), with verdicts like **CONFIRMED/DENIED** on claims (e.g., scout_5878 verifies `evolve.py` schema ops, not tensor evolution). Reveals intent: Yanantin as a *benchmarking harness* for epistemic AI scouts, tension between "composable tensors" and raw LLM trial/error.

**Strand 2: Claude Hooks — Puppet Strings from .claude/**  
`.claude/hooks/` (capture_compaction.py, chasqui_pulse.py, ots_stamp.py, pipeline_attestation.py) + state JSONs (.pulse.lock, heartbeat_state.json) hint at tight Anthropic integration. `chasqui_heartbeat.sh` pulses scouts; `precompact_tensor.py` hints at tensor compaction before Claude ingest. Confusing: `.claude/ubuntu-vm.claude/` mirrors project skills/docs — Yanantin *ingests itself* into Claude? Assumption: human-AI duality via hooks automating provenance/OTS stamps on code changes.

**Strand 3: Experiment Fractal — data/ as Infinite Regress**  
`data/compaction_experiment/` (20+ UUID dirs with raw/cleaned_messages.json, reasoning_anchors.json, stats.json) and `noninferiority/` (per-UUID baseline/treatment verdicts.json) scream A/B testing on summaries/compactions. Surprising: `disposition_experiment/` timestamps like `aggressive_20260306_064223.json` suggest RLHF-like tuning on "dispositions." Mirrors cairn scouts — project eats its own output for self-improvement, assuming tensors are compressed conversations.

**Strand 4: Apacheta Core — Tensor Alchemy**  
`src/yanantin/apacheta/` owns the magic: operators/evolve.py (schema evolution), compose.py, models/tensor.py. Jabberwock normalizes; awaq weaves/materializes. Tension: "epistemic observability" via provenance/timestamps, but src feels nascent vs. docs' maturity. `ots/` (6500+ .ots proofs) timestamps *everything* — blockchain-level immutability for tensors?
