The `coverage.py` module is responsible for monitoring which files have been reviewed by scouts and when. It maintains a coverage map, assigning epoch zero to files never reviewed. This allows the system to prioritize unstudied code.

The `scan_cairn_coverage` function parses scout report files (using a glob pattern) to extract file paths and their corresponding review timestamps. It builds a dictionary mapping project-relative file paths to the timestamp of the most recent scout report referencing them.

This approach ensures that new code gets a higher chance of being reviewed, addressing the issue of popular files being repeatedly reviewed while newer code is ignored.
