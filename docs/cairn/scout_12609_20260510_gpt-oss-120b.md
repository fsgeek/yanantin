### Closing  
The MCP reference docs paint a picture of a **high‑level orchestration layer** (Claude Code) that abstracts away the gritty details of authentication and tool access, promising a “plug‑and‑play” experience. Yet the contracts it relies on—secure token vaults, automatic refresh, implicit agent privileges—are **implicit**; they are described in prose but not anchored in visible code or explicit configuration schemas.
