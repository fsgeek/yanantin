- The **similarity calculation** is **pixel-based** (`np.mean(diff) / 255.0`), which means:
  - It’s **not perceptually aware**—two frames with *different colors* but *same composition* might be deduplicated.

- **Surprising:** The **default is `remove_duplicates=True`**, meaning the GIF builder **assumes users don’t want redundancy**—even if they do.

**What it made me think:**
