### What This Project Seems To Be Doing

The project runs structured experiments involving:
- Session-based agent interactions with checkpoint recovery
- System prompt blocks tracked as discrete "handles" stored in regions (SYSTEM, TOOLS, DURABLE, EPHEMERAL)
- Wire protocol logging (`wire.jsonl`) capturing all communications
- Benchmark experiments for evaluating instruction adherence, coherence retention, needle-in-haystack tasks
- Evaluation results stored in JSON/JSONL with detailed telemetry
