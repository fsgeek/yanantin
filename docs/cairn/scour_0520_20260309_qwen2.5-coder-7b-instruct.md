# Yanantin

Yanantin is an experiment to see if we can use a causal language model to
intervene in a research program.

It's a prototype of a system that can:
1. Extract data from the research program
2. Use it to produce new data
3. Compare new and old data to see if the program is continuing its mission

This is a work in progress. The prototype is a pipeline of AI systems.
We're working on a new one now.

## Yanantin 0

Yanantin 0 was the first prototype. It's a pipeline of AI systems that
can:
1. Extract data from the research program
2. Use it to produce new data
3. Compare new and old data to see if the program is continuing its mission

The pipeline is a collection of Python scripts that run in a Docker
container. The scripts are:
- `collector.py` - collects data from the research program
- `composer.py` - composes data into a tensor
- `model.py` - trains a model on the tensor
- `evaluator.py` - evaluates the model
- `updater.py` - updates the research program
