#### Strand 4: “Three kinds of same” is the core conceptual payload
This is the clearest thematic center of the tensor.

The author preserves a filesystem identity theory:
- Path = name
- Inode / `(st_ino, st_dev)` = object identity
- Content hash = semantic identity

And then maps common filesystem events to those layers:
- Same inode, different paths → hard links
- Same path, different inode → rename/new object at old name
- Different path, different inode, same hash → duplicates
- Same path, same inode, different hash → in-place modification

This is not merely descriptive; it is used as an argument against premature collapse. The author explicitly connects it to T23:
- A path-only system collapses three identity layers into one.
- The result is false interpretation of rename as modification.
- The “I between them” is where rename patterns live.

That last line is philosophically loaded, but I take it as metaphor rather than formal claim. I’m not importing meaning beyond the text: the author is clearly emphasizing that distinctions carry explanatory power.

Also notable:
