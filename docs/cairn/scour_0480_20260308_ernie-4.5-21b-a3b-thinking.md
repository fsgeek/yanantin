### Preamble  
The target `src/yanantin/activity` implements a temporal fact-store abstraction for epistemic observability. Its core lies in **separating immutable factual records (Facts) from mutable cursor states (Anchors)**, enabling composable tensor infrastructure. Key files include `store.py` (interface), backends (`arango.py`, `duckdb.py`, `memory.py`), `models.py` (data schemas), and `anchor.py` (anchor service).

### Strands  
#### 1. **Fact/Anchor Duality**  
- **FactRecord**: Schema-agnostic provider data (immutable once stored).  
- **MemoryAnchor**: Timestamped cursor state (mutable via `update_cursor()`).  
- **Connection**: Anchors derive validity from Facts (via `materialize()`).  
- *Source*: `models.py` (lines 38, 64, 84); `anchor.py` (lines 101-104).  

#### 2. **Backend Abstraction & Optimization**  
- **ArangoDB**: Uses ArangoDB's AQL with persistent indexes on `(provider_id, timestamp)` for O(log n) fact queries.  
- **DuckDB**: Relies on SQL composite indexes for temporal queries, storing timestamps as ISO 8601 strings.  
- **Memory**: Bisect-based linked lists for O(log n) per-provider fact retrieval.  
- **Insight**: Backend choices trade off consistency guarantees (DuckDB/ArangoDB) vs. resource efficiency (Memory).  
- *Source*: `arango.py` (line 110), `duckdb.py` (line 42), `memory.py` (line 70).  

#### 3. **Anchor Service Workflow**  
- **Write Gate**: `update_cursor()` (sets `updated=True`) + `get_handle()` (sets `referenced=True`).  
- **Flush**: Persists anchors only if both flags are set.  
- **Freeze**: Creates tensors by materializing anchors (`materialize()` queries latest facts).  
- **Implication**: Anchors enable **ephemeral views** without caching, but `materialize()`'s late-binding fact queries could cause latency.  
- *Source*: `anchor.py` (lines 72, 91, 114).  

#### 4. **Immutability Enforcement**  
- Duplicate detection (e.g., `store_fact()` rejects existing UUIDs).  
- Thread safety via `RLock` (all backends).  
- **Risk**: Backend-specific failure modes (e.g., ArangoDB’s AQL constraints) could violate immutability.  
- *Source*: `store.py` (line 42), `arango.py` (line 52), `duckdb.py` (line 82).  

#### 5. **Tensor Integration**  
- `MemoryAnchorService.freeze()`: Converts anchors into tensors via `TensorRecord` (provenance + strands).  
- **Gap**: No direct interface for tensor storage; depends on external `ApachetaInterface`.  
- *Source*: `anchor.py` (line 142).
