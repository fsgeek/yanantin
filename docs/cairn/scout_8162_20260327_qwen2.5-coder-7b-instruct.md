## Introduction

Claude Code allows you to extend its functionality with hooks. Hooks are custom scripts that run at specific points in the Claude Code execution flow. By creating hooks, you can enforce rules, validate operations, and automate tasks. This reference provides guidelines and examples to help you develop effective hooks.

## Types of Hooks

Claude Code supports two types of hooks:

- **PreToolUse Hook:** A hook that runs before a tool is used. This hook is useful for checking or enforcing conditions before an operation is performed.
- **PostToolUse Hook:** A hook that runs after a tool is used. This hook is useful for validating or logging the results of an operation.

## Hook Configuration

Hooks are configured using a JSON file located at `.claude/hooks.json`. This file defines the hooks to be run at specific points in the execution flow. Here's an example configuration:

```json
{
  "PreToolUse": [
    {
      "matcher": "Write|Edit",
      "hooks": [
        {
          "type": "prompt",
          "prompt": "File path: $TOOL_INPUT.file_path. Content preview: $TOOL_INPUT.content (first 200 chars). Verify: 1) Not in /etc or system directories 2) Not .env or credentials 3) Path doesn't contain '..' traversal. Return 'approve' or 'deny'."
        }
      ]
    }
  ],
  "PostToolUse": [
    {
      "matcher": "Write|Edit",
      "hooks": [
        {
          "type": "prompt",
          "prompt": "Operation details: $TOOL_INPUT. Verify: 1) No path traversal 2) No credentials exposed 3) Operation was intended. Return 'approve' or 'deny'."
        }
      ]
    }
  ],
  "SessionStart": [
    {
      "matcher": "*",
      "hooks": [
        {
          "type": "command",
          "command": "bash ${CLAUDE_PLUGIN_ROOT}/scripts/load-context.sh"
        }
      ]
    }
  ],
  "Stop": [
    {
      "matcher": "*",
      "hooks": [
        {
          "type": "prompt",
          "prompt": "Review transcript. If code was modified (Write/Edit tools used), verify tests were executed. If no tests were run, block with reason 'Tests must be run after code changes'."
        }
      ]
    }
  ],
  "Notification": [
    {
      "matcher": "*",
      "hooks": [
        {
          "type": "command",
          "command": "bash ${CLAUDE_PLUGIN_ROOT}/scripts/log-notification.sh"
        }
      ]
    }
  ]
}
```
