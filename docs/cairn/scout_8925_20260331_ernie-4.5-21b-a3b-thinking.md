- **Thought**: The system assumes developers will manage configurations correctly. Real-world errors could crash tools before hooks run.  
- **File**: `advanced.md` (Dynamic Hook Configuration example)

- **Observation**: Prompt hooks like "File Write Validation" require explicit criteria (e.g., "Not system directories"). Designing unambiguous prompts is non-trivial.
